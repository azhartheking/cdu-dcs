# CDU Unit 11 — DCS Training Simulator

A browser-based control-room (DCS) training simulator of an atmospheric crude distillation unit (6.5 MTPA, Bach Ho / Dubai crude): crude preheat and two-stage desalting, fired heater H-1101, main fractionator T-1101 with pumparounds and side strippers, overhead system, naphtha stabilizer, dryers, PSVs and flare. Start-up from cold, crude switches, upset drills, shutdown.

**Open it:** double-click `Start CDU Simulator.bat` (folder above), or the single-file version. Works in Microsoft Edge or Google Chrome; can be installed as an app when served over http.

Documents: [Student manual](docs/) · printable [checklists](forms/checklists.html) and [operator log sheet](forms/logsheet.html).

*Independent educational project. Training model built from public training material and textbook theory: values are not design data and must never be used to operate a real unit. Not affiliated with any refinery, licensor or vendor.*
